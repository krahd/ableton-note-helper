# Changelog

## 1.1.0 — 2026-09-10

- Added twelve ordered jazz phrases spanning bebop vocabulary, chromatic enclosures, essential cells and major/minor ii–V–I lines.
- Added numbered pad steps, including repeated visits to the same pad and descending contours.
- Added compact phrase-position resolution and explicit warnings when a device cannot display a complete phrase.
- Added deterministic phrase-data and layout-resolution tests.

## 1.0.0 — 2026-07-22

- Added iPad 13 × 5, iPhone 5 × 5 and Push 8 × 8 layouts.
- Added scales, modes, chords, arpeggios and exact voicings.
- Added multi-chart comparison, root linking, duplication and persistent preferences.
- Added octave-aware chord recognition with inversion and alternative-name support.
- Added one-tap clearing beside the selected-note chips.
- Added deterministic layout, theory, recognition and voicing tests.
- Added responsive and accessible controls, credits, launch metadata and documentation.
